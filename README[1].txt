CraveDash Food Delivery Website
================================

Run:
1. Extract the ZIP.
2. Open index.html in Chrome/Edge.
3. No PHP, MySQL, or server is required.

Features:
- Login/Register using localStorage
- Search and category filtering
- Add to cart
- Quantity increase/decrease
- Remove items / clear cart
- Subtotal and delivery fee calculation
- Free delivery for orders >= ₹499
- Checkout and order confirmation
- My Orders page
- Cart, account, and orders persist after refresh
- Responsive layout

Demo login:
Register a new account from the profile button. The account is stored only in this browser.
